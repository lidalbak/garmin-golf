## Meaning and uncertainty

[OSM's golf-hole mapping contract](https://wiki.openstreetmap.org/wiki/Tag:golf%3Dhole) describes a way ordered from tee toward green. We use the first point as the mapped tee-area reference and last point as the target. `center` deliberately preserves that last source point, with `targetKind: osm-hole-endpoint`. It is not a verified polygon center, selected tee marker, current cup location or daily pin. UI distance should be labelled an OSM mapped target estimate.

Green association is derived by point-in-polygon: exactly one closed OSM `golf=green` polygon contains the endpoint for all 36 holes. The complete source polygon is preserved and its own OSM way URL retained. Polygon points can support directional front/back estimates, subject to source accuracy and GPS error. Green polygons at Bogstad include edits from 2016; snapshot download date does not establish survey freshness.

Par and handicap are source tags. Bogstad holes 12 and 16 both claim stroke index 18; those two normalized stroke indices are null. Their source value is preserved separately as `sourceStrokeIndex: 18`. No assumed replacement index is supplied. This means Stableford/handicap results that require those indices must remain unavailable for affected holes until independently verified.

Hazards are nearby context only. A polygon is attached if any source vertex lies within 100 m of any hole-line vertex. This association is an explicit display heuristic, not an assertion of official hole membership, a complete hazard inventory, penalty area status, carry distance or playability. Source URLs and full point lists are preserved. Raw `features` also include fairways and tees, without invented per-hole associations.

## Losby deferred

`data/losby-raw.osm` is a partial raw download, excluded from playable normalized courses. The requested box contains only 7 hole ways and 6 greens. More importantly, [Losby's official course page](https://losby.no/banene) and [2026 nine-hole notice](https://losby.no/nyheter/banene/spill-9-hull-pa-losby) say Østmork has temporary nine-hole operation during rehabilitation. Historical hole numbers must not silently become the current nine-hole routing. Import only after authoritative 2026 routing and geometry are established. Vestmork may be investigated separately.

## Acquisition observations

Overpass `overpass-api.de` returned HTTP 406 and `overpass.kumi.systems` / `overpass.private.coffee` returned HTTP 500 during this session. OSM API's larger bbox returned HTTP 400 with an explicit 50,000-node limit. The smaller bounding boxes above succeeded; the normalizer requires exactly one numbered hole 1–18 and complete node references. Field accuracy, current course status and proprietary Garmin-equivalent green contours remain unverified.
